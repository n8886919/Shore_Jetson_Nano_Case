## 合成方式

- 先以主畫面作辨識子母畫面的 UI 參考，不直接把設定面板開著當作主要跟拍畫面。
- 原生介面以 1024×600 設計；收合設定時影片區是 `(0,0)` 起的 960×540，右側有 64 px 控制區，底列在 Y=544、56 px 高。設定展開時影片區為 768×432，右側為設定面板。
- 子母畫面中完整保留 App 的比例與辨識度，不把它拉成另一套陌生 HUD。模擬 surfer 影片、辨識框和狀態是示範資料，要與同一目標和時間對齊；字體、按鈕、顏色與排版沿用真實 App。
- 主畫面右上為關閉、縮小、設定，設定開啟時三顆一起隱藏。不要誤套遠端 Web 的「齒輪在底列」布局。
- 目前來源的辨識框為青綠色 `#29d6bd`、約 2 px，框旁標示 `ID` 與追蹤編號；影片內跟拍容許區為約 1 px 的同色細線。文字／描邊可隨輸出等比例縮放。
- 這裡只有 UI 參考圖，**沒有能直接載入動態影格的可執行 App 或 UI 渲染器**。若要動態介面，可在 Blender 合成中依這個真實畫面佈局替換影片區和資料，或在取得 App 的合法執行環境後使用離線模擬資料擷取；不要把截圖當作已有可執行元件。
- 截圖內「離線預覽」「開始追蹤」與禁用設定都是離線狀態，不能直接當作正在追蹤的實測畫面。宣傳片應保持模擬狀態一致，並用簡潔的「模擬畫面」標示；不編造實測 FPS 或辨識精準率。

此參考不要求連接相機、啟動正式服務、操作舵機或改原 App。另一台電腦可先用這些圖片完成分鏡與視覺開發。

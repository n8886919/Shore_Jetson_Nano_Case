# Shore Jetson：60 秒宣傳片交接

本文件是使用者於 **2026-11-19** 指定的最新創作目標。這次工作是在另一台電腦製作，不是在原主機改 CAD。製作流程和來源保護見 [Blender 交接](blender-handoff.md)。

## 必須達成

- **總長 60 秒**，從精美工程組裝走入岸邊使用情境，最後讓人看懂自動跟拍衝浪者。這是模擬宣傳展示，不能寫成實機辨識／運動已驗收。
- 組裝段整組要和目前 FreeCAD 的預設呈現上下顛倒：**螢幕在上、Jetson Nano 在下**。在 Blender 共同父層／鏡頭中處理，不修改 FCStd。
- 大底板是**黑色磨砂金屬**；3D 列印外殼是**奶白色塑膠外觀**。其他未確認材質依展示需要合理搭配。
- 產品要和攝影腳架、露營電源接合，再呈現岸邊的實用場域。道具選擇是視覺展示，不是硬體採購驗證。
- 監視器模型已指定使用 [Remastered Cameras — bunny man](https://sketchfab.com/3d-models/remastered-cameras-ea93654b1d3a4017a129e76f90df9c47)，詳見素材文件中的已指定項目；不要另換成腳架素材附帶的 DSLR。
- 有模擬的 surfer、海浪與衝浪板。可採卡通／柔和風格 3D 插畫，但**不要方塊人／Minecraft／voxel 人物**；要自然四肢、比例和衝浪姿勢。
- 子母畫面的辨識介面使用 **我們 Shore Jetson App 的畫面**，不能另外設計一套陌生的科技 HUD。已附 [實際 App 離線截圖與使用說明](../render/references/app/README.md)。
- 使用者希望一起尋找免費模型；可先推薦候選並整理比較，同時準備腳本和構圖。[目前素材候選](promo-assets.md) 尚未下載，也不是已決定採用。
- agent 應主動優化鏡頭、分鏡、轉場與節奏，不必機械照抄以下秒數；保留上述敘事順序及 60 秒總長。

## 分鏡起稿（可優化）

| 時間 | 敘事與畫面 |
|---|---|
| 0–4 秒 | 精緻工程產品的開場：奶白外殼、黑色金屬底板、五金與局部細節；柔光、清楚輪廓，避免一開始就像粗略 CAD 螢幕錄影。 |
| 4–20 秒 | 組裝動畫：轉接板 → Nano → 底板／雲台 → 顯示器 → 止擋螺絲螺母。螢幕在上、Nano 在下；螺絲穿入、螺母位置與插槽方向清楚，避免零件穿過實體。Nano 五金與底板固定螺絲在顯示器插入前處理。可並行呈現次組裝以維持節奏。 |
| 20–24 秒 | 完整組裝的產品特寫；環繞或拉遠，讓背景逐漸轉為海邊，保持產品的視覺連續性。 |
| 24–40 秒 | 攝影腳架接上設備、露營電源出現並接上供電線，構圖走入岸邊使用場域；設備對準海面、腳架落地、線路有合理去向，不出現不合理浮空接合。 |
| 40–56 秒 | 模擬 surfer 在浪上滑行，設備視覺上跟隨；出現 App 子母畫面，能看懂同一位 surfer 被辨識／追蹤。主副畫面的衣著、板色、動作、浪向與時間一致；App 的字體與按鈕要看得清楚。 |
| 56–60 秒 | 以產品、海面與簡潔品牌文字 **Shore Jetson** 收尾，停留足夠閱讀，不編造辨識精準率、FPS、續航或防水等規格。 |

建議第一版為 1920×1080、16:9、30 fps；若採此設定，時間軸共 **1,800 frames**，例如 1–1800。可以換幀率，但最終片長必須仍為 60 秒。未指定音樂、旁白或音效；若 agent 建議加入，先說明風格與合法免費來源，不擅自選用來源不明音訊。

## App 子母畫面

用主畫面交代「設備在岸邊看海」，子畫面呈現 App 的跟拍視角。子畫面使用同一段衝浪動作的另一鏡頭或裁切，不是另一位人物或不同波浪片段。

保留真實 App 的外框、按鈕、色彩、文字與影像比例；把模擬影像及對應辨識框放進影片區。原截圖的離線文字不是正式辨識效果，不能原封不動當成追蹤結果；需要一致的模擬狀態與字幕標示。具體版面、哪些畫面是參考而非可執行 App，見截圖旁的 README。

子母畫面與設備上實體顯示器可共用同一個 App 輸出。辨識框必須隨同一目標移動；不讓框停在人物以外、穿越不同鏡頭或在剪接後引用上一個位置。

- 可考慮用 Google 的生圖／生影片製作海岸氣氛、浪況、背景或短轉場，再與 Blender 渲染合成。工程組裝、產品形狀和 App UI 保持可控，避免生成過程把零件、字體或按鈕變形。
- 不預設訂閱等同付費 API 額度，不要求 API key 來使用網頁會員福利。先確認目的地主機上可用的 Gemini／Google Flow 入口與帳號權益。
- 先用 Blender 的幾個關鍵畫面與低成本預覽確認構圖，再針對有明確用途的短片段生成；不盲目大量重試。保留 prompt、模型、長度、生成設定、下載檔名與實際消耗，方便接續。
- 官方文件於查詢日列出 Plus 的月度 Flow 額度，且可在個人資料／點數活動頁查看餘額；條件會變更，請以當下帳號與生成前顯示為準，不把本文件當成剩餘點數證明。
- 使用已有方案與可用額度；額度不足時回到 Blender 或其他合法免費素材，不購買額度、不升級訂閱。Google 工具不是完成作品的必要依賴。

## 驗收與交付

先完成來源保護、關鍵畫面和 animatic，再做正式渲染；agent 應持續推進到可檢視的成果。模型挑選期間可以並行做不依賴選材的工作，不把每個可逆調整都變成確認關卡。

- 原 FCStd 與使用者 STL 雜湊保持不變，工程裝配的零件相對位置沒有被美術調整改掉。
- 組裝段清楚呈現螢幕在上、Nano 在下；接合順序、螺絲、螺母和滑入方向可理解，沒有明顯穿模。
- 三段敘事連貫、產品與人物風格一致，實際 App UI 可辨識；同一位 surfer 與辨識框保持同步。
- 用實際輸出的媒體檢查解析度、幀率、60 秒長度、黑幀／跳幀／貼圖遺失與中文字型。檢查開頭、中段、轉場、追蹤及收尾，不能只看一張樣圖。
- 交付可重建的腳本／設定、必要場景與素材來源清單、預覽及最終 MP4。說明實際執行的命令、檢查結果、生成資源消耗與仍未驗證的物理條件。

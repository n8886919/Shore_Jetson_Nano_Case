## 選材與取得方式

- 優先找 CC0，或能滿足署名要求的 CC BY。用於宣傳圖時，不把 NC、ND、Editorial-only 或來源不明的模型當成已可用素材。
- 逐一確認**實際模型頁面與隨檔授權**，不要只依搜尋標題的「Free」字樣判斷。上表已標出只看得到搜尋索引的來源。
- [Sketchfab 官方下載說明](https://sketchfab.com/developers/download-api) 表示 Download API 需要 Sketchfab 帳號驗證；是否能在目的地主機取得檔案仍待確認，不預設使用者已登入。
- 人物先看輪廓、四肢、比例與是否能擺出合理的衝浪姿勢，不因為模型標成 low-poly 就接受方塊造型。
- 道具風格可以統一調整，但保持產品外殼奶白色、大底板黑色磨砂金屬。腳架與電源不能搶過產品主體。
- 不下載或購買付費方案；若某來源不可用，繼續找其他免費候選。可先做構圖與腳本，不必等所有素材到齊。
- 採用後在本文件追加作者、精確授權連結、資產頁、下載格式／版本、取得日期與本地檔名，並保留必要署名。先確認是否允許再散布，才將第三方網格、貼圖或含它們的 `.blend` 放入公開 repo；否則記錄合法取得與重建方法。
